# 数学讲解的针对性指导

按主技能确定深度，只补当前数学问题需要的内容，不自动进入竞赛论文流程。公式计算、证明与直观解释各有作用，不能互相冒充。

## 从对象和条件进入

先说明研究的量、集合或结构，定义新符号、定义域及必要单位；矩阵运算说明维度，概率问题说明事件和随机变量。区分题目已知、定义、假设与待证结论。用户只问某一步时，定位该步使用的条件，不重讲整章。

讲定理时解释它解决什么问题、条件在哪里起作用、结论适用到哪里；讲计算方法时解释为何选择这一变换，而不只给公式名称。

## 让推导可追踪

保留非显然步骤及其依据，区分等价变形与单向推出。除法、平方、开方、对数、换序和取极限若引入条件或改变解集，交代相关影响。常规代数可紧凑，不逐符号附一句空泛说明。

例：从 x² = x 得 x(x−1) = 0，再分解得到 x = 0 或 x = 1。不能直接除以 x 而漏掉 x = 0；如要除，先分别讨论 x = 0 与 x ≠ 0。这类例子用于解释条件如何影响变形，而不是背诵“不能约分”。

证明按实际逻辑组织，说明关键构造、分情况或反证的理由。数值例子帮助形成直觉，不能代替一般证明；数值近似须区分精确关系、误差与适用精度。

## 按子主题定位真正需要展开的内容

按用户实际卡点选择下列子主题。每段中的输入和数字均为教学条件；换到用户材料时重新核对，不能把示例答案直接套用。只输出当前问题所需的解释，不照搬本文件的备课结构。

### 集合、逻辑与证明

卡点是量词或条件方向时，把“谁先选、谁能依赖谁”解释清楚。例如在实数中，∀x∃y，使 y>x 为真，可在给定 x 后选 y=x+1；∃y∀x，使 y>x 为假，因为选定 y 后仍可取 x=y+1。对比应落在量词顺序，而非只翻译符号。

若问充分与必要，使用同一命题检查两个方向，如“能被 4 整除”足以推出“偶数”，偶数却未必能被 4 整除。若问证明思路，解释如何从目标找可用条件，不能把一个例子当一般证明。

### 函数与方程

卡点是“为什么答案丢了”时，同时追踪定义域与解集。例：实数方程 √(x+2)=x 先要求 x≥0；平方得到候选 x=2、−1，代回仅 2 成立。说明平方保留了必要关系，却可能扩大候选集。

若问参数方程，先定位会使系数为零、分母为零或条件失效的参数，再讨论一般情形。若问函数值或反函数，转而解释输入输出与一一对应，不继续套用求根步骤。

### 极限与连续

卡点是“该点无定义，为什么仍有极限”时，用 f(x)=(x²−1)/(x−1) 展开：x≠1 时等于 x+1，所以 x→1 的极限是 2，但这并没有定义 f(1)。补定义 f(1)=2 才能讨论该处连续。

若卡在左右极限，可比较 x/|x| 在 0 两侧分别趋于 −1、1；若卡在多元极限，沿两条趋近路径得到不同极限值可否定极限存在，但检查几条路径得到相同极限值不能证明存在。讲严格定义时再联系距离控制，不只说“无限接近”。

### 导数与微分

卡点是复合函数时，把依赖链展开。例：z=x²+y²，x=t，y=t²，则 dz/dt=2x·1+2y·2t=2t+4t³；这里 2x 是固定 y 时的偏导，不能直接作为沿该路径的总导数。

若问极值，改用 f(x)=x³ 在 0 导数为零但没有局部极值，定位还缺什么判定条件。若问微分近似，说明线性项与余项及近似所在邻域，不将“很小”当精确相等。

### 积分与级数

卡点是“积分为什么可能为零”时，比较 ∫[-1,1] x dx=0 与该区间曲线和横轴围成的面积 1：前者正负抵消，后者累积非负面积。用分割小区间解释被积量和权重，不只展示反导函数。

若问级数收敛，区别通项与部分和：1/n→0，但调和级数发散，可把 (2^(k−1),2^k] 内项分组，每组和至少 1/2。若问换序或逐项求导，回到具体收敛条件，不从这个反例泛推所有级数。

### 线性代数

卡点是“不可逆是否等于无解”时，用 A=diag(1,0)：Ax=(2,0) 有 x₁=2、x₂任意的无穷多解，Ax=(2,1) 无解。以像空间解释区别，再联系秩与可解性。

若问矩阵乘法，追踪先后两次线性映射及维度；若问特征向量，说明非零向量 v 满足 Av=λv，结果是 v 的标量倍数，允许 λ 为负或零，不能只说“方向不变”；若问换基，区别对象本身与坐标表示。不要对所有线代问题都从行列式讲起。

### 概率与统计

卡点是条件概率方向时，给明确频数：A 组 40 人中 10 人会编程，B 组 20 人中也有 10 人会编程。在全部 60 人中等概率抽取，P(会编程|A)=10/40，而 P(A|会编程)=10/20。重点是条件改变了分母所对应的人群。

若问独立性，用 P(A∩B)=P(A)P(B) 连接“得知一个事件是否改变另一事件概率”，不把互斥当独立。若问估计或检验，分别解释样本统计量、总体参数及抽样过程，不能沿用事件概率的口吻解释所有推断量。

### 优化与数值方法

卡点是“梯度为零为什么还不是最优”时，区分驻点与最小点，例如最小化 −x² 时 x=0 的梯度为零，却是最大点。约束问题还须说明可行方向，不能直接照搬无约束结论。

若问数值停止条件，用尺度示例：求 10⁻¹²x=1，精确解是 10¹²；取近似值 10¹²−1，在精确算术下残差绝对值为 10⁻¹²，但变量绝对误差为 1。解释绝对误差与相对误差的区别，以及为何不能只用一个绝对残差阈值判断所有问题。若问迭代过程，选择实际方法的一次更新，分别交代初值、更新依据与误差判断。

## 解释公式时的层次选择

第一次出现核心公式时，说明它关联哪些量、在什么条件下成立，以及本题如何使用。读者卡在推导时，展开依据和中间关系；卡在符号时，解释符号对应对象；卡在应用时，代入能暴露关键条件的小例子。不要每次将全部符号定义、推导和用途再写一遍。

有多种证明思路时，围绕当前问题选一条连贯主线。只有比较能解释“为什么想到这样做”时才加另一种方法，不编造发现过程。构造辅助量时指出它解决哪个具体障碍，如将所求关系转换为已知定理的适用形式。

## 回答追问时缩小到断点

“这一步怎么来的”应指出用到的定义、定理或运算，而不是重复最终式子。“这个条件为什么必要”应展示它在证明中的位置，或在适合时给去掉条件后的反例。“公式能算但不理解”可增加几何、数量或概率解释，再与原式逐项对应。

示例：由 x² = 4 得 x = ±2；写 √(x²) 时在实数范围应为 |x|。只写 x = 2 同时混淆了主平方根与方程的两个解。解释应定位这个区别，无需重新铺开所有根式运算。
