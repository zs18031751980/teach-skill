# 数学讲解的针对性指导

按主技能确定深度，只补当前数学问题需要的内容，不自动进入竞赛论文流程。公式计算、证明与直观解释各有作用，不能互相冒充。

## 从对象和条件进入

先说明研究的量、集合或结构，定义新符号、定义域及必要单位；矩阵运算说明维度，概率问题说明事件和随机变量。区分题目已知、定义、假设与待证结论。用户只问某一步时，定位该步使用的条件，不重讲整章。

讲定理时解释它解决什么问题、条件在哪里起作用、结论适用到哪里；讲计算方法时解释为何选择这一变换，而不只给公式名称。

## 让推导可追踪

保留非显然步骤及其依据，区分等价变形与单向推出。除法、平方、开方、对数、换序和取极限若引入条件或改变解集，交代相关影响。常规代数可紧凑，不逐符号附一句空泛说明。

例：从 x² = x 得 x(x−1) = 0，再分解得到 x = 0 或 x = 1。不能直接除以 x 而漏掉 x = 0；如要除，先分别讨论 x = 0 与 x ≠ 0。这类例子用于解释条件如何影响变形，而不是背诵“不能约分”。

证明按实际逻辑组织，说明关键构造、分情况或反证的理由。数值例子帮助形成直觉，不能代替一般证明；数值近似须区分精确关系、误差与适用精度。

## 按子主题定位真正需要展开的内容

下面各行只在对应主题出现时使用，是备课参考，不是输出目录。

| 子主题 | 优先说明的关系 | 有帮助的演示 | 避免的省略或误导 |
|--------|----------------|--------------|--------------------|
| 集合、逻辑与证明 | 命题的对象、量词范围、充分与必要条件 | 改变量词顺序或去掉一个条件，比较命题是否仍成立 | 将“存在”当“任意”，把命题的逆命题当作原命题 |
| 函数与方程 | 定义域、映射、解集以及变形是否等价 | 对同一方程保留限制逐步求解，再代回原式 | 只报根而不处理增根、漏根或参数特殊值 |
| 极限与连续 | 自变量趋近、函数值变化与极限存在的条件 | 左右趋近或两条路径的对照，联系严格定义 | 将靠近某点等同于取该点值，用图上平滑代替连续性依据 |
| 导数与微分 | 局部线性近似、变化率和复合关系 | 先写函数依赖链，再解释链式法则中的每一项 | 把偏导与沿路径的总变化混淆，把导数为零当作极值充分条件 |
| 积分与级数 | 累积量、收敛对象及交换运算的条件 | 用分割求和解释积分；用部分和区分数列与级数 | 未说明条件就交换求和、积分或极限；混淆有向积分与几何面积 |
| 线性代数 | 空间、线性映射、基、秩与方程可解性 | 用小矩阵跟踪向量怎样被映射，再联系抽象结论 | 把矩阵可乘当作可交换；遇到方程就默认矩阵可逆 |
| 概率与统计 | 样本空间、条件、独立性与随机量 | 列出频数或条件子集后计算概率，再写符号式 | 把互斥当独立，把 P(A\|B) 当 P(B\|A) |
| 优化与数值方法 | 目标、约束、可行域、迭代与停止条件 | 展示一个实际迭代及残差变化，区分局部与全局结论 | 将收敛或小梯度直接等同于已找到全局最优解 |

## 解释公式时的层次选择

第一次出现核心公式时，说明它关联哪些量、在什么条件下成立，以及本题如何使用。读者卡在推导时，展开依据和中间关系；卡在符号时，解释符号对应对象；卡在应用时，代入能暴露关键条件的小例子。不要每次将全部符号定义、推导和用途再写一遍。

有多种证明思路时，围绕当前问题选一条连贯主线。只有比较能解释“为什么想到这样做”时才加另一种方法，不编造发现过程。构造辅助量时指出它解决哪个具体障碍，如将所求关系转换为已知定理的适用形式。

## 回答追问时缩小到断点

“这一步怎么来的”应指出用到的定义、定理或运算，而不是重复最终式子。“这个条件为什么必要”应展示它在证明中的位置，或在适合时给去掉条件后的反例。“公式能算但不理解”可增加几何、数量或概率解释，再与原式逐项对应。

示例：由 x² = 4 得 x = ±2；写 √(x²) 时在实数范围应为 |x|。只写 x = 2 同时混淆了主平方根与方程的两个解。解释应定位这个区别，无需重新铺开所有根式运算。
